# 10万条商品月度销售数据清洗与自动化报表生成

## 📌 项目背景
模拟市场调研/咨询公司日常数据处理需求。针对包含重复记录和缺失值的 10 万条原始商品月度销售数据，进行清洗与自动化排版，解决人工 Excel 拉透视表耗时且易出错的问题。

## 🛠️ 技术栈
- Python 3
- Pandas / NumPy
- Matplotlib (待加入)
- Excel (openpyxl)

## ⚙️ 核心处理流程
1. **数据清洗**：基于业务主键（商品ID + 日期）去重，使用 `fillna(0)` 填补缺失值，并转为可空整数 `Int64`。
2. **时间周期化**：将字符串日期转为标准时间格式，提取 `Period`（月度周期）。
3. **二维交叉表**：使用 `pivot_table` 按商品（行）和月份（列）聚合数据。
4. **双格式导出**：一键导出“横排交叉表”（看趋势）和“竖排长表”（方便筛选），满足不同业务场景。
5. **宽表转长表**：使用基础 `for` 循环遍历还原底层数据拉平逻辑（演示代码）。

## 📊 结果展示
运行代码后，自动生成 `商品月度销售报表_横排.xlsx` 和 `商品月度销售报表_竖排.xlsx`。

## 📁 文件说明
- `main.py`：核心代码文件
- `商品月度销售报表_横排.xlsx`：横排结果（137列）
- `商品月度销售报表_竖排.xlsx`：竖排结果（长表）
